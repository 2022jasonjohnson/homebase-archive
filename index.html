Project Description

The Homebase Archive is an interactive web project that invites all users to explore or "revisit" the/their past. The project itself leaves interpretation open to the viewer as they explore old abstract entry logs.

My project (me, hello) is a culmination of my experience as a web designer and my experience with experimental coding. As far as the design goes, I wanted to build a fake os and interactive application that allows a user to explore a visualized database or old, and ambiguous memories. I wanted to use the design of an old computer interface to evoke a sense of nostalgia and to create a space that feels like a personal archive. The user can click through different folders and files. As the creator, I encourage you to explore and observe the different abstract memories that I included in the project. This project was made using Photoshop, Illustrator, HTML/CSS, AND JavaScript.

Please enjoy this interactive experience!
